About ConfHub

ConfHub is a simple conference management website. Visitors can find events, register for them and manage their bookings. Administrators can add, edit and remove conferences and control booking statuses.

This is an educational project made for the Web Programming course.

Privacy

This demo stores all data only in your own browser (localStorage). Nothing is sent to a server. Do not use real passwords.

Terms

The website is a student project and is provided as is, without any guarantees. Bookings are not real and no payments are processed.
