# ConfHub — Simple Conference Management System

Open `index.html` in a browser (or use VS Code Live Server).

Features:
- Home page with 8 sample conferences
- Conference search and category filtering
- Conference details and sample program
- Registration and login
- Join/cancel conference registration
- Personal profile and registrations
- Responsive design

**Important:** This is a browser-only educational demo. User data, including passwords, is stored unencrypted in localStorage. It is **not secure** and must not be used for real accounts.

Not implemented: admin panel and CRUD, database/backend, password reset, profile editing, real ticket/payment flow, dynamic schedules, server-side validation.

Suggested demo: Register -> Conferences -> Details -> Join -> Profile.
